# 🎓 CASE 0 — DETECTIVE ACADEMY

Before entering the real investigations, every recruit must complete the Detective Academy.

Case 0 is your SQL training environment.

You learn the fundamentals of querying the investigation database.

---

## Your First Query

Start by viewing the evidence locker:

```sql
SELECT * FROM evidence_locker;
```

This retrieves every record from the evidence locker.

---

## Filtering Evidence

You can filter records using `WHERE`.

```sql
SELECT *
FROM evidence_locker
WHERE status = 'Missing';
```

This asks:

> Which evidence items are currently missing?

---

## Counting Records

SQL can also summarize information.

```sql
SELECT item_type, COUNT(*)
FROM evidence_locker
GROUP BY item_type;
```

This groups evidence by type and counts how many records exist for each type.

---

## Sorting Evidence

You can reconstruct the order in which evidence entered the system:

```sql
SELECT *
FROM evidence_locker
ORDER BY date_added ASC;
```

`ASC` means ascending order.

---

# 🧑‍💻 SQL INVESTIGATION EXAMPLES

### Find all suspects

```sql
SELECT *
FROM suspects
WHERE case_id = 1;
```

### Find suspicious evidence

```sql
SELECT *
FROM evidence
WHERE case_id = 1;
```

### Examine forensic reports

```sql
SELECT *
FROM forensics
WHERE case_id = 1;
```

### Reconstruct the timeline

```sql
SELECT *
FROM timeline
WHERE case_id = 1
ORDER BY time ASC;
```

### Combine information

```sql
SELECT
    s.name,
    s.motive,
    f.analysis_result
FROM suspects s
JOIN forensics f
    ON s.case_id = f.case_id
WHERE s.case_id = 1;
```

The more complex the investigation becomes, the more important SQL becomes.
